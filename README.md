# 每一笔 · 手续费与做 T 计算器

可直接在浏览器使用的静态网页，支持 A 股、ETF、LOF 交易手续费计算，以及同数量先卖后买的做 T 保本价、盈利买回价和净收益测算。

- 支持输入成交金额或价格 × 数量。
- 支持最低佣金、分笔计费、多笔比较及 CSV 导出。
- 可以修改佣金、过户费及印花税口径。
- 设置与比较清单仅保存在各自浏览器中，不上传到服务器。

预设股票佣金万分之 1.654、每笔最低 5 元；ETF 佣金万分之 1、每笔最低 0.20 元；LOF 佣金万分之 1，最低佣金待确认。A 股过户费暂按另收 0.01‰估算，卖出印花税预设 0.5‰。这些是账户示例，请按自己的券商规则调整。

纯静态网页，无需依赖或构建。GitHub Pages 从 `main` 分支根目录发布。下载 `index.html` 后也可离线使用。

所有结果为按所填规则计算的估算，以实际交割单为准。
